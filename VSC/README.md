## Features

- **Responsive Design**: Mobile-first approach, optimized for all device sizes

- **Fast Loading**: WebP image format, lazy loading, and optimized CSS
- **Professional Layout**: Clean, modern design with smooth animations
- **Contact Form**: Direct inquiry submission capability

## Quick Start

### Local Development

1. Clone or download this project
2. Open `index.html` in a web browser
3. All images must be added to the `images/` folder

### Required Images

The website expects these image files in the `images/` folder:
- `strongco-logo.webp` - Company logo
- `hero-background.webp` - Main hero section background (recommended: 1920x1280px)
- `fire-door-frame.webp` - Surveys section image
- `fire-door-double.webp` - Gallery image 1
- `fire-door-single.webp` - Gallery image 2
- `fire-door-hinge.webp` - Gallery image 3
- `fire-door-certifire-hinge.webp` - Gallery image 5
- `fire-door-exit.webp` - Gallery image 6

## Deployment

### Option 1: Netlify (Recommended - Free)
1. Go to [netlify.com](https://www.netlify.com)
2. Sign up / Log in
3. Drag and drop the project folder
4. Site goes live automatically
5. Connect a domain under Site Settings

> Netlify will provide a free SSL/TLS certificate and serve your site over HTTPS automatically. To enforce HTTPS for all visitors, enable "Force HTTPS" in your Netlify site settings.

### Option 2: Vercel
1. Go to [vercel.com](https://vercel.com)
2. Import your project
3. Deploy automatically
4. Connect a custom domain

### Option 3: GitHub Pages (Free)
1. Create a GitHub repository
2. Push this project to the repo
3. Enable GitHub Pages in repository settings
4. Choose `main` branch as source
5. Site will be live at `https://yourusername.github.io/repo-name`
